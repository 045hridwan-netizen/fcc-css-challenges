# freeCodeCamp Responsive Web Design Challenges

Repositori ini berisi kumpulan proyek dan tantangan pengkodean yang diselesaikan sebagai bagian dari kurikulum **Responsive Web Design** dari freeCodeCamp. Fokus utama dari repositori ini adalah penataan visual web, penerapan gaya antarmuka, dan pemahaman konsep CSS3 yang rapi, responsif, serta terstruktur.

---

## 🛠️ Teknologi dan Fitur

* **CSS3 Styling:** Penataan tampilan antarmuka web menggunakan properti modern seperti warna, tipografi, spacing (`margin` & `padding`), dan border.
* **Box Model & Layout:** Pemahaman mendalam mengenai struktur elemen web, kalkulasi area konten, serta tata letak elemen secara konsisten.
* **Clean Code Practices:** Penulisan aturan CSS yang rapi, terorganisir, dan efisien untuk memudahkan proses perancangan serta *debugging* tampilan.

---

## 📁 Struktur Proyek

Daftar modul latihan CSS yang telah dan sedang diimplementasikan dalam repositori ini:

- **01:** *Desain Menu Cafe* - Halaman menu cafe.
- **02:** *Desain Kartu Bisnis* - Profile-image, portfolio-link dan social media.
